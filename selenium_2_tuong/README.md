#  Instructions for Running a Maven Project in Visual Studio Code
Requirements:

Java at least 17 installed

Maven installed

Visual Studio Code with the following extensions:

Extension Pack for Java

Maven for Java

Debugger for Java

##  Configure Java SDK

Open the Command Palette (Ctrl + Shift + P)

Search and select Java: Configure Java Runtime

In the Project Settings section, make sure the Project SDK and language level are set to Java 17


##  How to Run Tests

```
mvn test

```
